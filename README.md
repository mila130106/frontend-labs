## Лабораторна робота №4 (CP4): Маршрутизація та спільний стан застосунку

### Маршрути
- `/` — головна сторінка (`HomePage`)
- `/traffic-light` — керування світлофором, орієнтацією та автоматичним режимом (`TrafficLightPage`)
- `/stats` — статистика та спільний стан світлофора (`StatsPage`)
- `/status` — компактний перегляд поточного стану (`StatusPage`)
- `*` — сторінка для невідомих URL (`NotFoundPage`)

### Архітектура
- Спільний макет `AppLayout` містить навігацію через `NavLink` та слот `<Outlet />`.
- `TrafficLightsProvider` є єдиним власником стану світлофора (`phaseIndex` / поточний сигнал, лічильники ручних натискань, орієнтація, автоматичний режим) і життєвого циклу таймера автоматичного перемикання.
- Провайдер підключено вище за маршрути, тому стан зберігається під час SPA-навігації між сторінками в межах поточної вкладки браузера.
- Компоненти `TrafficLights`, `StatsBar` і `Light` отримують дані через `props` і не залежать від `react-router`.
